# minivpn

Личный VPN для Windows на временном сервере Serverspace. Нода создаётся при нажатии «Пуск» и удаляется после завершения сессии, поэтому не нужно оплачивать постоянно работающий VPS.

## Возможности

- **Hysteria2 и VLESS + Reality** на одной ноде; клиент автоматически выбирает доступный транспорт.
- **Раздельное туннелирование:** российские сайты, игры, торренты и выбранные приложения идут напрямую.
- **Блокировка рекламы** через правила sing-box.
- **Автоматическое управление нодой:** создание, установка по SSH, проверка реального трафика и удаление.
- **Замена недоступной ноды:** при SSH-тайм-ауте или блокировке адреса приложение пробует другую локацию.
- **Контроль расходов:** тариф, стоимость текущей сессии, баланс и месячный лимит видны в панели.
- **Автоматическое завершение:** по команде пользователя, по простою или по ограничению длительности.
- **Журнал и диагностика:** результаты проверок, репутация IP, экспорт истории в CSV.
- **Подключение телефона** по QR-коду, пока нода существует.

## Требования

- Windows 10/11 x64.
- Права администратора для создания TUN-интерфейса.
- Аккаунт [Serverspace](https://serverspace.ru) с достаточным балансом.
- Отдельный проект Serverspace для minivpn и API-ключ с правами:
  - серверы — изменение;
  - финансы — просмотр.

Отдельный проект важен: сторож на ноде использует API-ключ, чтобы удалить сервер, если ПК исчез из сети. Компрометация ключа не должна открывать доступ к другим проектам.

## Установка

1. Скачай `minivpn.exe` и `minivpn.exe.sha256` из [Releases](../../releases).
2. При необходимости проверь хеш в PowerShell:

   ```powershell
   Get-FileHash .\minivpn.exe -Algorithm SHA256
   Get-Content .\minivpn.exe.sha256
   ```

3. Запусти `minivpn.exe` и подтверди запрос прав администратора.
4. В приветственной форме вставь API-ключ Serverspace и нажми «Записать».
5. Отключи другие VPN с TUN и нажми «Пуск».

Первый запуск может занять больше времени: приложение скачивает sing-box, создаёт сервер, ждёт SSH и устанавливает ноду. Прогресс и ошибка конкретного этапа отображаются в панели.

## Как работает сессия

1. Приложение получает у Serverspace минимальную конфигурацию и актуальную цену.
2. Создаётся временная Ubuntu-нода с публичным адресом.
3. По SSH загружается установочный скрипт: он ставит сторож и sing-box, настраивает Hysteria2 и Reality.
4. После установки SSH отключается — это штатная мера безопасности, а не ошибка подключения.
5. ПК проверяет TCP, Reality handshake и скачивание 256 КБ. Затем запускается TUN.
6. Нода удаляется при остановке, простое, завершении приложения или срабатывании ограничения времени.

Если SSH или проверка трафика не проходят, приложение может создать одну замену в другой локации. Прежняя нода удаляется только после создания замены, чтобы хостер не выдал тот же адрес повторно.

## Настройки и данные

Приветственная форма запрашивает только API-ключ; остальные параметры имеют значения по умолчанию. В настройках можно изменить:

- месячный лимит и порог предупреждения;
- длительность сессии и условия простоя;
- локацию и SNI для Reality;
- папки игр и `.exe`, которые не должны использовать VPN;
- автозапуск вместе с Windows.

Локальные данные находятся в `%LOCALAPPDATA%\minivpn`:

- `settings.json` — настройки и API-ключ, зашифрованный через Windows DPAPI;
- `journal.db` — локальный журнал сессий;
- `minivpn.log` — журнал работы и ошибок;
- файлы sing-box.

Ключ не встроен в исходный код и не передаётся в панель. Не публикуй `settings.json`, логи с адресами нод и другие локальные данные.

## Маршрутизация

Через VPN идёт всё, кроме исключений:

- домены `.ru`, `.su`, `.рф` и `geosite-category-ru`;
- адреса `geoip-ru`;
- обнаруженные игровые библиотеки Steam, Epic, Riot, GOG и добавленные вручную папки;
- выбранные программы и торрент-клиенты;
- рекламные домены блокируются.

Одновременно использовать другой VPN с TUN нельзя: маршруты будут конфликтовать, а проверки ноды могут пойти через чужой сервер.

## Сборка из исходников

Нужен Go версии, указанной в [`go.mod`](go.mod).

```bat
git clone https://github.com/marienbaum77/minivpn.git
cd minivpn
build.bat
```

Готовый `minivpn.exe` появится в корне репозитория. Бинарные файлы, локальные настройки, журналы и результаты тестов исключены через `.gitignore`.

## Разработка

```bash
go test ./...
python -m unittest discover -s internal/node -p watchdog_test.py
go test -tags e2e -v -timeout 30m ./test/e2e/
```

E2E требует Docker. Он поднимает Ubuntu-контейнер, выполняет настоящую SSH-установку, проверяет Hysteria2 и Reality, клиентскую конфигурацию и самоудаление ноды через поддельный API. Реальный аккаунт Serverspace и платные серверы тесты не используют.

CI дополнительно запускает `go vet`, race-тесты, ShellCheck, Windows-сборку и E2E. Тег `v*` создаёт GitHub Release с бинарником и SHA-256.

### Структура

```text
cmd/minivpn          запуск, UAC, автозапуск
internal/app         связывает настройки, хостера, сессию и панель
internal/serverspace API Serverspace и выбор конфигурации
internal/session     жизненный цикл сессии и удаление ноды
internal/node        SSH-установка, ключи, скрипт ноды и сторож
internal/client      конфигурация sing-box и исключения
internal/check       проверки канала и репутации IP
internal/tunnel      управление sing-box на ПК
internal/journal     SQLite и экспорт CSV
internal/settings    локальные настройки и DPAPI
internal/ui          трей, WebView2 и локальный API панели
test/e2e             полный стенд с Docker
docs/adr             архитектурные решения
```

Словарь проекта: [`CONTEXT.md`](CONTEXT.md). Архитектурные решения: [`docs/adr`](docs/adr).

## Ограничения

- Поддерживается только Windows; нода работает на Ubuntu.
- Доступность Hysteria2 зависит от того, как сеть пользователя обрабатывает UDP/QUIC. При проблемах клиент может использовать Reality.
- Проект не обходит все возможные блокировки и не гарантирует «чистую» репутацию выданного хостером IP.
- Стоимость и доступность конфигураций определяются Serverspace.
