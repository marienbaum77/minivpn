# Нода создаётся на сессию и удаляется после неё

В Serverspace (США) почти вся цена сервера — это диск и IP: диск 25 ГБ стоит 308 ₽ в месяц, IP 123 ₽, а весь минимальный тариф — 438 ₽. Выключенный сервер стоит почти столько же, сколько работающий, и один только простаивающий диск съедает больше месячного лимита. Поэтому нода создаётся при старте сессии и удаляется при её конце, а между сессиями не стоит ничего. Каждая сессия получает новый IP, и его репутация проверяется каждый раз.

## Considered Options

- **Одна нода, которую включают и выключают.** Отклонено: ~430 ₽ в месяц за выключенную ноду, хотя запуск быстрее и IP постоянный.
- **Edge Gateway с постоянным IP** (123 ₽ в месяц), за которым меняются ноды. Отклонено: шлюз даёт только NAT и Firewall, а постоянный IP съедает больше половины лимита ради неизменного адреса.

## Consequences

- Запуск — это полное создание сервера. По словам хостера, это ~40 секунд, плюс установка sing-box по SSH ([ADR 0003](0003-install-over-ssh.md)).
- Ключи Reality и Hysteria2 хранит приложение, они одни и те же для всех нод. Меняется только адрес.
- Если ПК пропал, нода должна удалить себя сама, а для этого ей нужен API-ключ хостера.
