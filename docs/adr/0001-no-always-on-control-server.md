# Нет круглосуточного сервера управления

Месячный лимит — 200 ₽, а один постоянно работающий сервер стоит дороже. Поэтому менеджер, бот, Prometheus/Grafana, пробы в РФ и Ansible-роли удалены, а проект стал приложением под Windows, которое само включает ноду на время сессии. Роль пробы из России играет ПК пользователя: он проверяет ноду при каждой сессии и пишет журнал.

## Consequences

- Нет подписок, пользователей и бота: нода личная. Телефон подключается по QR-коду только во время сессии.
- Удалённый код остаётся в истории git, если понадобится постоянный режим.
